# Swiggy Restaurant Analysis

Project Overview
--
Analysing Swiggy restaurant data using MySQL to clean, transform, and explore restaurant information and identify meaningful business insights.

Objective
--
To understand restaurant distribution, ratings, cuisines, pricing, and other business patterns using SQL.

Dataset 
--
Source: Kaggle
Link: [ kaggle.com/datasets/ashishjangra27/swiggy-restaurants-dataset ]
Contains restaurant-level information from 600+ Indian cities, including restaurant details, ratings, cuisines, pricing, and location information.

Project Workflow
--
- Download and explore the dataset using SQL
- Clean and prepare the data for analysis
- Perform exploratory data analysis
- Answer business questions using SQL queries
- Identify key insights from the analysis

Business Questions
-- 
1. How many cities have Swiggy restaurants listed?
2. How many restaurants are listed in each city?
3. Which restaurant chains have the most branches?
4. Which cities have the highest average restaurant ratings?
5. Which restaurants have a rating of 4.5 or higher and more than 1,000 ratings?
6. Which cuisines have the highest average ratings?
7. Which cities have lower-cost restaurant options?
8. Which cities have higher average ratings with relatively lower average costs?
9. Which restaurants in Delhi have the highest number of ratings?
10. Which restaurant chains have the highest average ratings?

Key Insights
--
The analysis transformed raw restaurant data into a structured dataset and used SQL to identify patterns in restaurant distribution, ratings, pricing, cuisines, and customer engagement

Files
--
* `swiggy_analysis.sql` — Data cleaning and exploratory analysis queries
* `swiggy.csv.zip` — Dataset
